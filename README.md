# LinguaQuest AI

Работающая локальная версия Telegram EdTech-приложения: React Mini App, FastAPI, aiogram 3, PostgreSQL, серверный lesson engine и интеграция Telegram Stars. **Это ещё не готовый к публичным продажам продукт.** Реальные Telegram-платежи, публичный HTTPS и AI-провайдер в этой среде не подключены. Голосовая система скрыта, продажи PRO/ULTRA запрещены сервером. Полный статус: [docs/STATUS.md](docs/STATUS.md).

## Быстрый запуск

Требуются Python 3.12+, uv и Node.js 24 с npm. Команды из корня репозитория:

```bash
bash scripts/setup.sh
bash scripts/dev.sh
```

Setup устанавливает зависимости по `uv.lock` и `package-lock.json`, создаёт `.env` из примера **только при отсутствии файла**, применяет Alembic-миграции и собирает frontend. Dev запускает API на порту 8000 и Mini App на 5173; Vite проксирует `/api` без CORS. Адреса служат для локальной разработки. Первичный вход — кнопка «Войти в режиме разработки». Это явно обозначенный режим без оплат; он недоступен в production. После входа: цель → первый урок → вопросы → результат → тарифы. Результаты сохраняются в `linguaquest.db`, а не в браузере.

Остановить dev: Ctrl+C. Данные сохраняются. Следующие задачи должны использовать существующий checkout; отдельный Git worktree не нужен.

## Что реализовано

- Проверка HMAC Telegram `initData`, срок 5 минут, защита от повторных полей, серверная сессия в HttpOnly cookie на сутки. Secure cookie в production; проверка Origin и Fetch Metadata для изменений.
- Онбординг с целью, ежедневной нагрузкой и часовым поясом; предварительная проверка 6 вопросов с честными ограничениями. Порядок рекомендуемых уроков учитывает цель и результат.
- 6 базовых уроков A1/A2, 8 диалоговых сцен LifeQuest с двумя подходящими сюжетными ветками, 3 испытания на отработку заданных фраз. Это стартовые модули, не полный курс CEFR и не свободная оценка устной речи.
- Серверная проверка ответов, альтернативные формулировки, объяснения, восстановление незавершённого урока, история, XP/Coins без повторных наград.
- Словарь из пройденных уроков, интервальное повторение, 25 достижений с проверяемыми условиями, ежедневная награда, косметические рамки, добровольный публичный недельный рейтинг.
- Счета XTR на 30 дней, pre-checkout, уникальные charge ID, продления, проверка истечения, отмена, возвраты и защита от параллельных подписок. Браузерный callback не выдаёт доступ.
- Реферальная ссылка через подписанный Telegram `start_param`: 100 косметических монет только после первого подтверждённого платежа, отзыв бонуса при возврате.
- Текстовый AI-адаптер OpenAI с входной и выходной модерацией, согласием, лимитом 30 успешных запросов/день, бюджетом токенов, таймаутами, защитой повторного UUID, кратким контекстом и аварийной остановкой. Без ключа — явная ошибка, не выдуманный ответ.
- Защищённая админка в Mini App: метрики, платежи/возвраты, редактирование JSON контента с проверкой версии. Начатые уроки сохраняют снимок контента. API изменения цен доступен администраторам.
- Outbox-worker: напоминания по местному времени и настройки отказа; уведомление о конце периода; повтор автоматического возврата конфликтных оплат.
- Выгрузка/удаление учебных данных. Финансовые записи сохраняются с псевдонимизированной учётной записью.
- Оригинальные логотипы, Lexi, SVG-сцены/персонажи/награды, рекламные SVG; светлая/тёмная тема, reduced motion, локально размещённый Manrope.

## Структура

```text
apps/miniapp/          React + TypeScript + Vite, включая админку
apps/bot/             aiogram handlers, polling entrypoint
services/api/         routes, models, security, billing, learning, AI
services/worker/      outbox и расписание
content/lessons/      исходный учебный контент с ответами (не frontend public)
assets/               оригинальная графика и маркетинговые SVG
infrastructure/       миграции, Dockerfiles, Nginx, Caddy
scripts/              setup/dev, webhook registration, backup
 tests/               backend, transport integration, PostgreSQL concurrency
apps/miniapp/e2e/      реальные browser-to-API сценарии
 docs/                запуск, ограничения, расходы и маркетинг
```

Все исходные JSON с ключами правильных ответов остаются в backend-образе; frontend получает только текущий вопрос. После ответа сервер возвращает его объяснение. Учебный контент хранится в файлах; административные изменения — в immutable DB-версиях.

## Проверки

```bash
.venv/bin/pytest -q
cd apps/miniapp
npm run build
npm run test:e2e
```

Браузерные тесты требуют запущенных API/Vite. В облачной машине используется `/usr/bin/chromium`. На другой машине выполните `npx playwright install --with-deps chromium` и `CHROMIUM_PATH='' npm run test:e2e`, либо задайте путь своего Chromium. Тесты блокируют внешний Telegram SDK и используют локальный dev-вход; это не тест Telegram WebView.

PostgreSQL concurrency suite требует отдельной одноразовой БД на порту 55432 и применённых миграций:

```bash
APP_ENV=development DATABASE_URL=postgresql+psycopg://linguaquest@127.0.0.1:55432/linguaquest .venv/bin/alembic upgrade head
TEST_POSTGRES_URL=postgresql+psycopg://linguaquest@127.0.0.1:55432/linguaquest .venv/bin/pytest tests/test_postgres.py -q
```

Без этой переменной два PostgreSQL-теста пропускаются. Детали и результаты: [docs/VALIDATION.md](docs/VALIDATION.md).

## Тестовое размещение без отдельного домена

Для @Linguaquesttest_bot подготовлен [вариант Render](docs/RENDER_TEST.md): один контейнер API + Mini App и PostgreSQL. Шаблон ещё не применён во внешнем аккаунте; ключ вводится в защищённых настройках Render. Основной бот не требуется.

## Production

См. [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md). Нужны собственный HTTPS-домен/хостинг, BOT_TOKEN, корректная поддержка, административные Telegram ID, пароль PostgreSQL и юридически утверждённые условия. Для AI отдельно требуется AI_API_KEY. **Не отправляйте ключи в чат и не добавляйте `.env` в Git.**

`COMMERCE_ENABLED=false` по умолчанию. Включать продажи можно только после проверок реальной среды Telegram. PRO и ULTRA остаются закрыты независимо от этого флага. Backend в production отказывается запускаться с dev-auth, SQLite, HTTP WEBAPP_URL или слабым webhook-secret.

OpenAPI: `/docs`, схема `/openapi.json` на API. Краткая карта: [docs/API.md](docs/API.md). Никакой публичный URL или успешный деплой не заявляется.
