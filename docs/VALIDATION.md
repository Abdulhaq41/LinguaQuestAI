## Покрытие

- Подписанные Telegram initData, подмена ID, срок действия, дубликаты полей, cookie-сессии, logout, запрет dev-auth в production и CSRF.
- Уроки, восстановление попыток, проверка ответов, снимки контента, отсутствие повторных XP, словарь, достижения, ежедневные награды и рефералы.
- Stars: суммы/валюта/владелец, уникальный charge, recurring/out-of-order, истечение, отмена/возврат и параллельные подписки. Запросы Telegram подменены транспортом; реальных денежных операций нет.
- Подарки: START/PRO/ULTRA, повторный UUID, конфликт параметров, продление/отзыв, истечение, приоритет тарифа, отсутствие фиктивного Payment, сохранение Stars и их продлений при активном подарке.
- Администрирование: отказ обычному пользователю, отсутствие самоназначения через настройки, поиск и фильтры, журнал, защита CSV от формул, пауза обучения с доступной отменой платежей/экспортом, завершение сессий, корректировка монет без отрицательного баланса, AI-пауза без списания лимита, удаление аккаунта с отзывом подарков. Диагностика не возвращает секретные значения.
- AI-провайдер: tier gate, квоты, согласие, timeout, учёт токенов, кеш UUID и moderation-block на синтетическом транспорте. Реальное качество AI этим не проверяется.
- aiogram Dispatcher: `/start`, `/id`, `/admin` владельцу и отказ постороннему; сетевой транспорт синтетический.
- Браузер: регистрация → бесплатный урок → сохранённый результат → paywall; настройки/язык/тема/отказ в админке; игровой раздел; владелец → подарок родственнику → платный PRO-урок → продление → отзыв → журнал → CSV → AI-пауза. Проверяются pageerror и отсутствие горизонтального переполнения. Скриншоты админки просмотрены.

Локальный API браузерных тестов использует вымышленный BOT_TOKEN `123456:synthetic-test-token` и ADMIN_TELEGRAM_IDS `8284379630`. Реальный Telegram SDK блокируется тестом; initData подписываются локально. Эти проверки не обращаются к аккаунту пользователя в Telegram или Render.

## Размещение и ограничения проверки

Владелец подтвердил `telegram=ready` и работу приложения на Render 9 ноября 2026. Новая админка ещё требует обновления существующего сервиса и настройки ADMIN_TELEGRAM_IDS. Сетевая политика облачной среды не позволяет независимо проверить onrender.com; локальные результаты не выдаются за проверку нового публичного deploy.

В предыдущем отчёте 5 ноября отдельно проверялись API/Web Dockerfiles, Nginx, Compose, Caddy и container smoke с сохранением данных после перезапуска. Эти проверки не повторялись для текущего изменения; Dockerfile не менялся. GitHub Actions обновлён для сценария админки с синтетическим токеном; результат нового удалённого запуска пока неизвестен.

Не проверены реальные Stars checkout/renewal/refund, AI-провайдер и его счета, голос, новый UI внутри iOS/Android Telegram WebView, нагрузка, screen-reader аудит, offsite disaster recovery и независимый security-аудит. Синтетический успешный платёж не доказывает успешную реальную оплату.
