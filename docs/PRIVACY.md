# Проект Privacy Policy — не утверждён для публичного запуска

Владелец и контакты контролёра данных, страна обработки, применимое право, сроки хранения, возрастные ограничения и механизм согласия родителей должны быть заполнены и проверены юристом до коммерческого запуска.

Сервис использует Telegram ID, отображаемое имя, выбранный язык/цель/часовой пояс, настройки, ответы на учебные задания, прогресс, XP, покупки и идентификаторы платежей. Telegram-аватар не загружается автоматически. Публичный рейтинг включается только по выбору пользователя. Открытых личных сообщений между учениками нет.

Текст AI отправляется OpenAI только при включённом согласии. В запросе используется ограниченный prompt и текущий вопрос, без Telegram ID и всей переписки. Провайдер получает текст и сетевые данные согласно своему договору. Разговоры не используются этим приложением для рекламного профилирования. Запись голоса не собирается: функция не реализована.

Уведомления об уроках включаются отдельно, в 18:00 выбранного часового пояса. Сервисные платёжные сообщения и сообщения о периоде доступа отделены от маркетинга. Маркетинговые рассылки не реализованы.

В профиле доступны выгрузка и удаление учебных данных. Сначала нужно отменить автопродление. После удаления сохраняются псевдонимизированные финансовые связи для обязательного учёта, предотвращения повторных событий и споров. Удаление из резервных копий следует отдельному утверждённому расписанию. Сейчас такие юридические сроки владельцем не установлены.

Сессия хранится в HttpOnly cookie, в production — Secure. Секреты не выдаются frontend. Финансовый доступ устанавливается только сервером. Для запросов субъекта данных используется контакт поддержки, который владелец должен настроить до запуска.
