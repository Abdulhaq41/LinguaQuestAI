# Визуальные ресурсы

- `branding/`: оригинальный кристалл-эмблема, квадратный/горизонтальный/монохромный SVG. Фон прозрачный.
- `mascots/lexi-generated.png`: оригинальная 2.5D-иллюстрация Lexi, созданная инструментом генерации изображений для этого проекта. Исходник сохранён; перед массовым mobile production нужен WebP/AVIF export с проверкой качества.
- `mascots/lexi-*.svg`: 12 лёгких процедурных вариантов. Некоторые выражения переиспользуют базовую позу; это не 12 уникальных сложных анимаций. CSS float и reduced-motion поддержаны.
- `backgrounds/`: остров и тематические SVG-сцены.
- `characters/`: пять оригинальных процедурных портретов.
- `achievements/`: 25 оригинальных SVG-эмблем.
- `marketing/`: шесть редактируемых SVG-обложек.

Случайные изображения из интернета не использованы. Manrope поставляется локально через @fontsource/manrope; лицензию OFL следует сохранять при распространении (см. файл лицензии пакета). Иконки lucide-react используют ISC. Отдельного набора PNG-логотипов, Lottie, профессионального аудиопакета и всех 30 требуемых категорий иллюстраций пока нет.
